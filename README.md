# AI-Learning

A collection of my projects and practical exercises in **Artificial Intelligence, Machine Learning, and Deep Learning**.

This repository documents my learning journey through hands-on projects, with a focus on understanding concepts, implementing models, and evaluating their performance.

## Projects

### 1. MNIST Digit Classification with PyTorch

A handwritten digit classification project implemented with **PyTorch**, featuring two neural network approaches:

* **MLP (Multi-Layer Perceptron)**
* **CNN (Convolutional Neural Network)**

The project covers the complete machine learning workflow:

* Data preparation
* Train / validation / test split
* Model architecture
* Training
* Validation
* Model evaluation
* Performance metrics
* Error analysis

[View Project →](./mnist_classifier/README.md)
